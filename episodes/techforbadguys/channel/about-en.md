# Earth Report: the English channel

A separate channel from the Arabic one (تقرير الأرض). The two audiences rarely overlap, and YouTube
recommends better when a channel speaks one language.

## Channel setup

YouTube Studio → Customization.

| Field | What goes in it |
|---|---|
| Name | Earth Report |
| Handle | Try in this order: `@EarthReportPeek`, `@AgentPeek`, `@EarthReportShow`, `@PeekReports`. YouTube shows which are free as you type; they have not been checked. |
| Picture | [avatar.png](avatar.png) (800 × 800, safe inside the circle; the same one as the Arabic channel) |
| Banner | [banner-en.jpg](banner-en.jpg) (2560 × 1440, everything important in the middle) |
| Description | The text below |
| Channel trailer | Part 1 of the cryptocurrency file, once it is up |

### Description

```
Agent Peek is an alien spy stationed on Earth. His job: work out what the humans are doing, and explain it to his commanders back home. Simply.

Each "field file" is a short series about something humans use every day and can't explain: Bitcoin and crypto, mobile phones and the internet, electricity, and more. Animated from the ground up, no background needed.

Open files:
• The Cryptocurrency File (5 reports)
• The Network File: phones, the internet and video calls (3 reports)

Subscribe so the next file reaches you.

The character, voice and animation are computer-generated. Sources are listed under every episode. Nothing here is investment advice.
```

### Channel keywords

YouTube Studio → Settings → Channel → Basic info.

```
Earth Report, Agent Peek, explained simply, how does it work, explainer, animated explainer, technology explained, Bitcoin explained, crypto explained, how the internet works, science for everyone
```

### Upload defaults

YouTube Studio → Settings → Upload defaults.

- Category: Education
- Video language: English
- Audience: not made for kids
- Comments: hold comments with links for review
